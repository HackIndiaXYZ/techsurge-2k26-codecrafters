# PROJECT CONTEXT: SETU (सेतु)

## Project Identity
- **Solution/Product Name**: Setu (सेतु)
- **Problem Statement/Theme**: "The Last Inch"

## Objective & Core Problem
Setu helps FPS dealers resolve the "last inch" of authentication and access failures in PDS delivery. The product allows a dealer to describe a failure, classifies the cause, uses a deterministic rule engine to select an officially verified fallback procedure, and presents resolution steps in the dealer's language.

## Project Phases & Status
- **Current Phase**: Architecture reconciliation/freeze completed.
- **Next Phase**: Monorepo scaffold.
